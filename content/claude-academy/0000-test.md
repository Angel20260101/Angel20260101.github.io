這是一篇**測試文章**，不是真正的課程筆記。它存在的目的只有一個：確認網站的排版、分類、自動部署都正常運作。確認完成後就會刪除。

## 重點整理

每篇課程筆記都會用同樣的結構，這樣回頭查的時候不用重新適應：

- **重點整理** — 這門課真正講了什麼，用我自己的話寫
- **限制與痛點** — 哪裡卡住、哪裡官方沒講清楚、哪些做不到
- **實作成果** — 需要實作的課才有，附上過程與產出

概念課沒有實作段落，就直接跳過，不會留一個空標題在那裡。

## 限制與痛點

測試文章沒有真正的痛點，但這裡示範一下各種排版元素長什麼樣子。

> 引用區塊長這樣。適合放課程裡的定義，或是我當下想記住的一句話。

行內程式碼像這樣 `claude --help`，程式碼區塊則是：

```bash
python3 build.py
```

表格也可以用：

| 項目 | 說明 |
| --- | --- |
| 網站產生器 | 自製的 Python 腳本，約 250 行 |
| 部署方式 | GitHub Actions，推上 main 就自動更新 |
| 費用 | 完全免費 |

## 實作成果

這次的「實作」就是這個網站本身：

1. 用 Markdown 寫筆記，放進 `content/` 對應的系列資料夾
2. `build.py` 讀取檔案開頭的設定（標題、分類、日期），編譯成 HTML
3. 推上 GitHub，Actions 自動建置並部署

未來要新增別的主題，只要在 `content/` 開一個新資料夾、在 `site.json` 加一行，首頁就會多一個系列——不限於 Claude 相關的筆記。

## 心得與限制

**心得**：靜態網站的好處是內容完全握在自己手上。Markdown 檔案就是原始資料，哪天想換個樣子，換掉樣板就好，筆記一個字都不用動。

**限制**：沒有留言、沒有訂閱、沒有追蹤數——這是刻意的選擇。這裡是學習紀錄，不是經營社群的地方。
